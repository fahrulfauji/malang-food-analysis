=========================================================
QUERY 5 — RATING DISTRIBUTION
=========================================================

Objective:
Analyze the distribution of restaurant ratings within the dataset.

---------------------------------------------------------
SQL QUERY
---------------------------------------------------------

SELECT
    ROUND(Rating, 1) AS rating_score,
    COUNT(*) AS total_menu_items
FROM restaurants
GROUP BY ROUND(Rating, 1)
ORDER BY rating_score DESC;
