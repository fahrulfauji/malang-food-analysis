=========================================================
QUERY 6 — MOST REVIEWED MENU ITEMS
=========================================================

Objective:
Identify menu items with the highest review mention volume.

---------------------------------------------------------
SQL QUERY
---------------------------------------------------------

SELECT
    Menu AS menu_item,
    SUM(Jumlah_Ulasan_Menu) AS total_menu_reviews
FROM restaurants
GROUP BY Menu
ORDER BY total_menu_reviews DESC
LIMIT 10;
